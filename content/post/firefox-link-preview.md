Saya baru menyadari bahwa Firefox mendukung fitur bernama [Link Preview](https://support.mozilla.org/en-US/kb/use-link-previews-firefox). Fitur ini memungkinkan penggguna untuk melihat pratinjau laman yang menampilkan judul, sebagian kecil isi laman, foto sampul, dan waktu baca. Sekilas fitur ini memang mirip dengan [Open Graph Protocol](https://en.wikipedia.org/w/index.php?title=Open_Graph_protocol&oldid=1349230950) yang populer digunakan di situs media sosial dan aplikasi pesan instan seperti WhatsApp.

Memang fitur ini terdengar sepele, tetapi menurutku ini adalah hadiah untuk web. Web yang saya maksud ini adalah situs web konvensional bukan *walled garden*. Setelah bertahun-tahun web terasa inferior hanya karena tidak bisa melihat *link preview* seperti halnya Facebook atau X (Twitter). Memang betul pemilik situs web bisa menambahkan dukungan *link preview* tetapi pada praktiknya jarang situs web yang mendukung *link preview*, apalagi untuk pranala pihak ketiga.

![firefox_link_preview](/img/firefox_link_preview.jpg)

Satu hal yang perlu dicatat adalah fitur ini mengharuskan Firefox untuk mengambil metadata dari pranala yang berarti pengelola situs web terkait dapat melihat alamat IP seperti halnya kamu mengunjungi situs web tersebut. Untungnya fitur ini tidak berjalan secara otomatis melainkan membutuhkan tindakan langsung, misalnya dengan mengklik kanan pranala dan memilih *link preview*. Selebihnya ini adalah fitur yang keren dan akan sering saya gunakan.
